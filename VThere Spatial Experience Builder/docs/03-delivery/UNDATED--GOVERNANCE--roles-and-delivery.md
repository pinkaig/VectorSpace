**Status:** Requires team and DigiPen confirmation

## Ownership matrix

| Role | Required ownership | Evidence |
|---|---|---|
| UXGD | Author workflow, panel hierarchy, WHEN -> DO builder, onboarding, usability tests, Jira/Scrum PM | user flows, usability findings, Jira ownership |
| IMGD | 3D canvas, viewport, gizmo rendering, asset library UI, runtime presentation, transitions, modest-hardware performance | viewport/gizmo demos, asset inventory, performance reports |
| RTIS | serialization/versioning, interaction engine, gizmo mathematics, undo/redo, persistence, publishing, accounts/access | package tests, API tests, migration tests, authoring-engine ownership |
| BFA optional | curated assets, environment dressing, iconography, panel language, visual polish | licensed asset catalog and visual design deliverables |

## Delivery gates

- **Weeks 1–2:** pitch approval, agreed trigger/action vocabulary, demonstration subject, custom component, scope, and roster.
- **Kickoff:** confirmed roles, Jira board, Scrum cadence, mentor/consultation arrangement, first sprint.
- **Technical spike:** one environment, one object, custom gizmo drag, save, reload, exact transform recovery.
- **Editor foundation:** scene tree, curated assets, canvas, inspector, gizmos, save/load, undo/redo.
- **Interaction/publishing:** WHEN -> DO builder, zones, multi-scene navigation, preview, published runtime.
- **Milestone 3:** non-programmer builds, previews, publishes, and opens a small exhibition on another device.
- **Post-Milestone 3 pilot:** observe people outside the team using the product without help; triage usability defects.
- **Final handoff:** demo-ready browser app, source code, tests, documentation, and reusable-code handoff under confirmed IP terms.

## Evidence and grading

Jira must make individual contribution visible while preserving team ownership. Each major subsystem should have an owner, reviewer, acceptance evidence, and linked test/demo. The 80% team / 20% individual assessment split must be confirmed against DigiPen's current rubric.
