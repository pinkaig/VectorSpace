# AI Declaration Template (Reflective, Framework-Agnostic)

This is not a compliance document — it's a short, first-person statement of how AI was used and what the author understands and can stand behind. Pairs with (doesn't replace) the jurisdictional disclosure. Write it in the author's voice, not a legalistic one.

The framing throughout: this is a record of understanding and ownership, not a confession. Nothing here should read as an admission of wrongdoing — using AI is expected. The point is to show the author knows exactly what it did and could explain or defend every part of the submitted work.

Fill every bracket, then read it back once — if any sentence sounds like it's apologizing or hedging, rewrite it as a plain statement of fact.

## Notes for the drafter (delete before finalizing)

- Keep sentences declarative. Avoid "I hope," "I tried to," "I think" — the author either verified something or they didn't.
- Don't inflate the verification section with steps the user didn't actually describe doing. If they only skimmed the code, say that rather than claiming a rigorous review — the declaration only has value if it's accurate.
- If the same project also needs a jurisdictional disclosure (Singapore/EU/Steam), draft this declaration second, after that document, so the two don't contradict each other on what was used where.
