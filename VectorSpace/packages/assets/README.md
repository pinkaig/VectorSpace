# @vectorspace/assets

Describes and loads media (images, video links, models) behind one resolver interface, with a cache and a content guard. Also holds the shared media-link parser the server mirrors.

- Version: 0.1.0 (see CHANGELOG.md)
- Code: `src/`; each `*.test.ts` sits beside the file it tests.
- Owner: unassigned. A teammate can take this package on; add your name here.
- Status: working, used by the editor and runtime. Larger system guide: https://github.com/gsherman01/Project5_Team17_DoReMi-yaki/wiki
